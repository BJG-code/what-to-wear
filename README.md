# what-to-wear

Run and ride clothing recommendations for the weather.

Live site: https://bjg-code.github.io/what-to-wear/

- What the app should do: [docs/spec.md](docs/spec.md)
- What's left to build, and in what order: [docs/gaps.md](docs/gaps.md)
- How each feature gets built: [docs/routine.md](docs/routine.md)

## Files

- `index.html`: the page and its styling
- `app.js`: finds your location, fetches the weather and shows the results
- `clothing.js`: the rules that decide what to wear
- `tests/`: automated checks, run on every pull request

Weather data from [Open-Meteo](https://open-meteo.com/).
